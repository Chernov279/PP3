# КиноРек API

Backend сервиса рекомендаций фильмов с гибкой настройкой алгоритмов подбора.

> **Демо:** [Swagger API](http://localhost:8000/docs) | **Frontend:** [http://localhost:3000](http://localhost:3000) | **Презентация:** [Ссылка]

## Описание
Бэкенд на FastAPI для управления пользовательскими предпочтениями и персонализированными рекомендациями.
Главная фича: Пользователь сам регулирует веса алгоритма (`популярность` / `новизна` / `персонализация`), получая выдачу под конкретное настроение.

## Технологический стек
| Компонент | Технология |
| :--- | :--- |
| **Язык** | Python 3.12+ |
| **Фреймворк** | FastAPI (Async) |
| **ORM / БД** | SQLAlchemy 2.0 + PostgreSQL + MinIO|
| **Auth** | JWT (Access + Refresh) |
| **Docs** | Swagger UI (OpenAPI) |

| **Тестирование** | Pytest |


## Запуск всего проекта
**Переменные окружения**

Перед первым запуском создайте файл .env в корне проекта (рядом с docker-compose.yml). Все переменные читаются через Pydantic Settings и попадают в контейнеры через docker-compose.yml.
```
# ============================================
# Проект
# ============================================
PROJECT_NAME=PP3
DEBUG=False
VERSION=0.2
CORS_ALLOWED_ORIGINS=http://localhost,http://127.0.0.1:8000
API_KEY=34228a17-40b0-46bc-b7f0-b286bf790cf6

# ============================================
# База данных
# ============================================
POSTGRES_DB=PP3
POSTGRES_HOST=db
POSTGRES_HOST_DEBUG=postgres
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_PORT=5432

# ============================================
# JWT
# ============================================
SECRET_KEY=09d25e094faa6ca2556c818166b7a9563b93f7099f6f0f4caa6cf63b88e8d3e3
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=3000
REFRESH_TOKEN_EXPIRE_DAYS=30

# ============================================
# MinIO / S3
# ============================================
MINIO_ENDPOINT=http://minio:9000
MINIO_PUBLIC_URL=http://localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET_NAME=avatars
```
Для синхронизации истории просмотров нужен файл с cookies пользователя. Он лежит по пути:

backend/src/api/users/env.py

Формат:
```python
COOKIES = {
    "kp_access_token": "...",
    "kp_refresh_token": "...",
    "uuid": "...",
    # остальные cookie из браузера
}
```
Как получить:

- Зайти на kinopoisk.ru в браузере и авторизоваться.
- Открыть DevTools → Application → Cookies → https://www.kinopoisk.ru.
- Скопировать нужные значения в словарь.

**Запуск приложения осуществляется через поднятие докера в командной строке** 
```bash
docker compose up -d --build
```

| :--- | :--- |

| API (Swagger) | http://localhost:8000/docs |
| MinIO Console | http://localhost:9001 |

Локальная разработка UI: см. [frontend/README.md](./frontend/README.md).
