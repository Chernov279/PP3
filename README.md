# КиноРек API

Backend сервиса рекомендаций фильмов с гибкой настройкой алгоритмов подбора.

> **Демо:** [Swagger API](http://localhost:8000/docs) | **Frontend:** [http://localhost:3000](http://localhost:3000) | **Презентация:** [Ссылка]

## Описание
Бэкенд на FastAPI для управления пользовательскими предпочтениями и персонализированными рекомендациями.
Главная фича: Пользователь сам регулирует веса алгоритма (`популярность` / `новизна` / `персонализация`), получая выдачу под конкретное настроение.

## Технологический стек
| Компонент | Технология |
| :--- | :--- |
| **Язык** | Python 3.12+ |
| **Фреймворк** | FastAPI (Async) |
| **ORM / БД** | SQLAlchemy 2.0 + PostgreSQL + MinIO|
| **Auth** | JWT (Access + Refresh) |
| **Docs** | Swagger UI (OpenAPI) |
| **DevOps** | Docker, Alembic (migrations) |

## Запуск всего проекта

```bash
docker compose up -d --build
```

| Сервис | URL |
| :--- | :--- |
| Frontend | http://localhost:3000 |
| API (Swagger) | http://localhost:8000/docs |
| MinIO Console | http://localhost:9001 |

Локальная разработка UI: см. [frontend/README.md](./frontend/README.md).

### Sprint 2 — Хранилище медиа: S3 / MinIO
Цель: Вынести хранение пользовательских файлов в объектное хранилище и реализовать работу с аватарами.

#### [Done] Реализовать S3StorageService
Описание: Обёртка над boto3 для работы с файлами: создание bucket, загрузка, удаление.
Критерии приемки:
- [x] Внедрение avatar_url в реляционную БД для корректного взаимдействия.
- [x] Публичная policy на чтение объектов.
- [x] Методы upload_avatar, delete_avatar работают.
Исполнитель: Chernov279

#### [Done] Развернуть MinIO в Docker
Описание: Поднять S3-совместимое хранилище рядом с API, подключить к общей сети.
Критерии приемки:
- [x] Сервис minio доступен по 9000 (API) и 9001 (Console).
- [x] Данные сохраняются в volume minio_data.
- [x] Сервис подключён к сети movierec-network.
Исполнитель: Chernov279

#### [Done] Исправление бага удаления аватара
Описание: Удаление из S3 не срабатывало из-за неверного парсинга ключа из URL.
Критерии приемки:
- [x] Ключ объекта извлекается по префиксу, а не split.
- [x] Файл реально пропадает из bucket после DELETE.
Исполнитель: Chernov279

#### [Done] Эндпоинты аватара профиля

Критерии приемки:

- [x] DELETE /users/me/avatar удаляет и файл, и ссылку в БД.
- [x] avatar_url возвращается в GET /users/me.
Исполнитель: Chernov279
