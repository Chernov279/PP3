# 🎬 КиноРек API

Backend сервиса рекомендаций фильмов с гибкой настройкой алгоритмов подбора.

## Описание проекта
Бэкенд-сервис на FastAPI для управления пользовательскими предпочтениями, историей просмотров и персонализированными рекомендациями. 

## Технологический стек
*   **Язык:** Python 3.12+
*   **Фреймворк:** FastAPI
*   **ORM:** SQLAlchemy (Async)
*   **База данных:** PostgreSQL
*   **Авторизация:** JWT (Access + Refresh)
*   **Документация:** Swagger (OpenAPI)

### Реализованные модули:
- [x] **Authentication:** Регистрация, Логин, OAuth2, Refresh, Logout.
- [x] **User Profile:** Данные пользователя, история просмотров, синхронизация с Кинопоиском.
- [x] **Films:** Поиск, жанры, похожие фильмы, управление избранное.
- [x] **Persons & Genres:** Поиск персон, управление избранное (жанры/ персоны).
- [x] **Recommendations:** Алгоритм с регулируемыми весами и фильтрами.
